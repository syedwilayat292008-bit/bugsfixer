# BugsFixer - Complete IT Solutions Website

A complete multi-page website for BugsFixer, an IT solutions company providing CCTV, Hardware & Networking services in Peshawar, Pakistan.

## 🌐 Live Website
Your website is now ready to deploy! The original is at: https://bugsfixer.netlify.app/

## 📋 Pages

### Main Pages
- **Home** (`/`) - Welcome page with services overview, contact info, and testimonials
- **About** (`/about`) - Company information, values, and why choose us
- **Contact** (`/contact`) - Contact form and business information

### Service Pages
- **CCTV Services** (`/cctv`) - Security camera installation and monitoring
- **Laptop Services** (`/laptopservices`) - Buy, sell, and repair laptops and computers
- **Electronics** (`/electronics`) - Electronics equipment and repair services
- **Security & Surveillance** (`/security`) - Fire alarms, burglar alarms, and integrated security
- **Telephone & Networking** (`/telephone-networking`) - PBX systems and network infrastructure

- **React 18** - Frontend framework
- **TypeScript** - Type safety
- **React Router DOM** - Multi-page routing
- **Tailwind CSS** - Styling
- **Lucide React** - Icons
- **Vite** - Build tool

## 💻 Development

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```
